# 逍遥叹 · 音乐动画

给胡歌演唱的《逍遥叹》做水墨风音乐动画的网页工具。载入你自己的歌曲音频，页面会自动分析节拍和段落，按歌词意象生成分镜，所有镜头、转场和字幕都卡在节拍上，最后导出成视频。

本仓库**不包含**原曲音频和歌词。请使用你自己拥有的音频文件，歌词可以从音乐 App 导出 LRC。

## 使用

1. 打开 `index.html`（直接双击即可，或用任意静态服务器）。
2. **壹 · 歌曲**：选择《逍遥叹》音频（mp3 / m4a / wav / flac）。分析在浏览器本地完成，不上传。
3. **贰 · 歌词**（建议）：粘贴或导入带时间轴的 LRC，点「应用歌词」。只有纯文本歌词时，点「打点同步」，边听边在每句开唱时按空格。
4. **叁 · 节拍**：如果画面节奏快了一倍或慢了一半，用「速度 ÷2 / ×2」修正；用「节拍偏移」微调对齐。
5. **肆 · 导出**：选 720p 或 1080p，点「导出视频」。按实时录制，耗时等于歌曲长度，期间保持页面在前台。Chrome / Edge / Safari 导出 MP4（H.264），其他浏览器导出 WebM。

分镜表里每个镜头都可以手动改选画面。

**精编分镜**：载入原版《逍遥叹》（5:13）和 48 句带时间轴的歌词后，页面自动换成按歌词逐句设计的 60 个镜头（「叁 · 节拍」里可以关掉）。歌词最好用逐字时间的增强型 LRC（`[mm:ss.xx]<mm:ss.xx>字<mm:ss.xx>字…`），镜头里的动作会落在唱到的那个字上。

## 离线逐帧渲染（可选）

需要 Node 18+、ffmpeg 和 Playwright。输出逐帧渲染的 H.264 + AAC MP4，不会因电脑卡顿掉帧：

```bash
npm i playwright && npx playwright install chromium
node tools/render.cjs 逍遥叹.mp3 逍遥叹.lrc 逍遥叹-音乐动画.mp4 --res 1080 --fps 30 --storyboard
```

`--storyboard` 强制使用精编分镜。单个镜头可以用 `node tools/preview-shot.cjs <镜头id> --times 0.5,2,4` 出联系表检查。

## 它怎么做到「卡点」

- **节拍**：频谱通量起音包络 → 自相关估计速度（偏向 85 BPM 左右的抒情速度）→ 动态规划节拍跟踪（Ellis 2007）。
- **强拍**：在四种相位里选和弦变化（色度）与低频鼓点最集中的一种。
- **段落**：按小节提取能量、音色、色度特征，用自相似矩阵的棋盘核找边界，再按能量标成前奏 / 主歌 / 副歌 / 间奏 / 尾声。
- **分镜**：精编模式下每句歌词有专门设计的镜头，切点落在该句第一个字之前最近的半拍上，镜头内的动作用逐字时间触发；转场有风、雨、云、尘、浪、雪、雾、墨晕、卷轴、光圈和闪白。通用模式下每句歌词按意象词典打分选画面（13 种），切点吸附到最近的强拍。
- **画面**：所有动画都是时间的纯函数（无状态），可以任意跳转、逐帧渲染。拍点驱动镜头轻推、涟漪、剑气、荷花开瓣、孔明灯升起、鹤群振翅等；歌词逐字落在十六分音符网格上；剑、泪、梦、花、雨等字出现的那一拍触发字效。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面与样式 |
| `js/audio.js` | 音频分析：起音包络、速度、节拍、强拍、段落 |
| `js/story.js` | 歌词解析、意象词典、分镜时间线 |
| `js/art.js` | 程序化水墨贴图、人物与器物 |
| `js/scenes-a.js`、`js/scenes-b.js` | 13 个场景 |
| `js/render.js` | 镜头、转场、天气、字效、歌词排版、片头片尾 |
| `js/kit/` | 绘画工具包：人物 `figures.js`、场景 `env.js`、特效 `vfx.js`、缓存与镜头运动 `core.js`（约定见 `docs/kit-spec.md`） |
| `js/shots/g01.js`–`g14.js` | 精编分镜的 60 个镜头 |
| `js/shots/storyboard.js` | 精编分镜表：每句歌词对应的镜头、歌词位置与转场（不含歌词文字） |
| `js/app.js` | 播放、分析流程、打点同步、分镜表、演示配乐、导出 |
| `tools/render.cjs` | 离线逐帧渲染脚本 |
| `tools/preview-shot.cjs` | 单镜头联系表预览 |

演示模式使用程序合成的配乐和自拟示例歌词，仅用于展示 13 种画面。
