# 剪影人物 `XYT.sil` 接口约定（第三版）

第三版只用剪影画人：每个姿势是一整块设计好的闭合轮廓，不做关节骨架，所以不会扭曲，也不会穿模。会动的只有挂在固定锚点上的头发、发带、袖口、下摆、披帛和斗篷边。

## 接口

```js
XYT.sil.draw(g, who, pose, x, y, h, t, opts)
```

- `g`：画布上下文，已经缩放到 1280×720 逻辑坐标。
- `who`、`pose`：人物和姿势，见下表。
- `x`、`y`：着地点（脚底中点；坐姿是臀部或坐面接触点；船上姿势是船板面）。
- `h`：这个人物**站立时**的身高（像素）。坐姿、卧姿按同一个人的比例缩放，所以同一个 `h` 下坐着比站着矮。
- `t`：时间（秒），驱动呼吸、二次运动和走路。
- `opts`：
  - `facing`：1 朝右，-1 朝左（侧影和走路用；背影可忽略）；
  - `wind`：风力 0..1；`windDir`：风吹向的方向，1 向右，-1 向左；
  - `body`：剪影主色，默认深墨 `#1d2128`；
  - `accent`：点缀色覆盖（发带、披帛、剑穗），null 用默认；
  - `rim`：轮廓光颜色，null 不画；`rimSide`：光从哪一侧来，1 右，-1 左；`rimWidth`：默认 `max(1, h/120)`；
  - `alpha`：整体透明度；
  - `glow`：0..1，周身柔光（用于回忆、梦境）；
  - `snow`：0..1，斗笠顶、肩上、头顶朝上的面积雪厚度（白色形状，平滑增长）；
  - `walkPhase`：走路相位偏移（秒）。

同时提供：

- `XYT.sil.poses`：`{ who: [pose, ...] }`。
- `XYT.sil.walkSpeed(h)`：走路姿势在这个身高下每秒前进的像素。镜头按 `x = x0 + facing * walkSpeed(h) * t` 移动人物，脚就不会滑。
- `XYT.sil.bounds(who, pose, h)`：`{ left, right, top, bottom }`，相对着地点的包围盒，用来避开歌词区。
- `XYT.sil.boat(g, x, y, len, t, opts)`：侧面木船（`y` 是船板面，`len` 是船长），可选 `opts.awning`（乌篷）、`opts.body`、`opts.rim`、`opts.rimSide`。船和人一起用时，人画在船板上，用同一个起伏量。

## 人物与姿势

| who | 外形要点 | 姿势 |
| --- | --- | --- |
| `old` 白发老者 | 白发挽髻、几缕散发；蓝色旧发带；微驼；长衫；背剑；腰挂葫芦 | `standBack` 背影站、`standSide` 侧影站、`sitSide` 侧坐（石凳/台阶）、`sitBack` 背影坐地、`sitSleep` 倚墙垂头睡（侧）、`sitBoat` 背影坐船、`fishSit` 披蓑戴笠侧坐垂钓（带钓竿）、`walkSide` 侧影长衫步 |
| `youth` 少年侠客 | 黑发高束、蓝发带两条长尾；挺拔；窄袖劲装外罩长衫；背剑 | `standBack`、`standSide`、`swordUp` 侧影举剑指天、`lieBoat` 仰卧（草帽盖脸、一腿屈起、葫芦在胸）、`laughSide` 侧影仰头、双臂微张、斗篷 |
| `heroine` 伊人 | 长发及腰、发间小簪；广袖长裙；淡粉披帛两端长垂 | `standBack`、`standSide` |
| `pair` 少年与伊人 | 并肩背影，她的头微偏向他的肩 | `standBack` |
| `traveler` 行路人 | 宽沿斗笠、蓑衣（边缘草穗）、长衫下摆 | `standSide`、`walkSide`、`leanSide` 顶风前倾站 |
| `boatman` 船夫 | 斗笠、短打、长篙 | `pole`：撑篙循环，每 2 秒一次（篙入水→前倾→收回），篙尖位置随时间平滑变化 |

## 质量要求

- **比例**：少年和伊人约 7.5–8 个头身，老者约 7 个头身且微驼；肩宽、手臂长度合理；坐姿腿长与站姿一致。
- **轮廓**：边缘流畅，没有锯齿、尖刺或自交。宽袖、下摆有布料垂坠的弧线。侧影只保留额、鼻、唇、下巴的轮廓线，不画眼睛。
- **二次运动**：
  - 用 2–3 个不同频率的正弦叠加，连续平滑；
  - 只在部件的末端摆动，根部固定在身体上；
  - 飘动部件画在身体后面，或者只在轮廓外缘飘，不能穿过身体；
  - `wind = 0` 时几乎静止，只剩呼吸。
- **长衫步**：
  - 腿藏在下摆里，下摆前后交替鼓起，脚尖交替微露；
  - 身体起伏 ≤ 0.8% 身高，没有夸张的抬腿；
  - 步频 1.3 步/秒左右，`walkSpeed(h)` 约为 0.42·h 每秒，和步幅严格匹配。
- **轮廓光**：只在迎光一侧，是贴着边缘的细亮线，不能是错位的整块。实现建议：先用轮廓光色填整个剪影，再把同一剪影向背光方向偏移 `rimWidth` 用主色填一遍，并裁切在原剪影内。
- **颜色**：主体是深色剪影，可以有极淡的衣褶明暗（同色系，差 5–10%）；点缀色只有一两处（发带、披帛、剑穗、葫芦）。
- **性能**：静态轮廓用 `Path2D` 预建；每个人物每帧 ≤ 1.5 毫秒。确定性：不用 `Math.random`。
