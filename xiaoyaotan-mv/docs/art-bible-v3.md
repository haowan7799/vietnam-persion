# 第三版美术守则（v3）

第二版的问题：人物脸型变形、眼睛粗糙、衣服穿模、动作扭曲、走路夸张、场景不合常识、节拍上人物抽动。第三版的每个镜头都必须遵守下面的规则，审核按这份清单逐条打分，任何一条不过就返工。

## 1. 人物：只画剪影，不画五官

- **禁止**：五官、眼睛、嘴、手指特写；脸部或眼睛的大特写；人物占画面高度超过 55%。
- 人物一律用 `XYT.sil`（`js/kit/sil.js`）画：一整块闭合轮廓，背影、侧影剪影或远景小人。侧影只保留额头、鼻梁、下巴的轮廓线，不画眼睛。
- **禁止使用旧的 `XYT.fig`**（关节拼接，会扭曲、穿模）。
- 区分角色靠轮廓和一处颜色：
  - 少年侠客：黑发高束、蓝色发带、背剑；
  - 白发老者：白发、微驼、背剑、腰间葫芦；
  - 伊人：长发及腰、广袖、淡粉披帛；
  - 行路人：斗笠、蓑衣；
  - 船夫：斗笠、撑篙。
- 光：轮廓光（rim）只在迎光一侧，宽 1–3 像素；身体其余部分是深色剪影，可带极淡的衣褶明暗。
- 二次运动只有头发、发带、袖口、下摆、披帛、斗篷边，必须挂在固定的锚点上。摆动用平滑的正弦叠加，幅度小（发带梢 ≤ 身高的 8%），频率 0.3–1.2 Hz，同一镜头内风向一致。
- 飘动的部件画在身体后面，或者只在轮廓外缘飘，绝不穿过身体。

## 2. 动作：慢、连续、合乎身体

- **不准**在节拍上换姿势、跳帧或突变。姿势整镜不变；需要变化时，在 ≥ 0.6 秒内连续插值。
- 呼吸：身体高度 ±0.4%，周期 3–4 秒。
- 走路只用 `XYT.sil` 的“长衫步”：腿被下摆遮住，只有下摆交替摆动和脚尖隐现，身体起伏 ≤ 身高的 0.8%。
  - 速度 = 步幅 × 步频：慢走步幅约 0.32 倍身高，步频 1.2–1.5 步/秒，所以每秒约走 0.4–0.5 倍身高的距离。
  - 脚不能在地上滑。只在远景或中远景里走。
- 船随水起伏：±2 像素，周期 3–5 秒，带 ≤ 1° 的摇摆。人跟着船动，不能和船分离。
- 物体运动服从物理：落体有加速度；纸、花瓣、雪受风和空气阻力，慢慢飘落；水波从落点向外扩散并衰减；烟向上升，再顺风飘散。

## 3. 镜头运动与卡点

- 镜头运动要缓入缓出（smoothstep 或 easeInOut）：
  - 推拉 ≤ 每秒 2%，整镜最多 1.00→1.10；
  - 平移 ≤ 每秒 35 像素；
  - 用视差分层：远景慢，近景快。
- 引擎在精编分镜模式下不再随拍缩放，镜头运动全部由镜头自己负责。
- 卡点只用环境元素：
  - 光的亮度起伏 5–15%；
  - 粒子成批飘起、涟漪、叶片或花瓣在拍点脱落；
  - 灯火摇曳、烟花绽放、钟摆、水滴落下。
  - 卡点的变化一律是“快起慢落”的包络（`c.be()`、`c.de()`），不是开关。
- 粒子不能凭空出现或消失：从画外进入，或者用 ≥ 0.3 秒淡入淡出。同屏小粒子 ≤ 300。

## 4. 常识与物理（审核必查）

- **比例**：门高约 1.2 倍人高；小船长约 3–4 倍人高；石桥栏杆约齐腰；人和树、房子比例正确。
- **透视**：一条地平线；越远越小、越高、越淡、越偏冷。人要站在地面或船上，脚下有接触阴影，不能悬空。
- **光**：每个镜头只有一个主光方向。太阳或月亮的位置、天空亮处、物体受光面、影子方向、轮廓光那一侧必须一致。夕阳低，影子就长；逆光时物体朝向镜头的一面暗。
- **倒影**：只出现在水面上，以水面线为轴上下翻转，比实物暗、偏冷、略模糊，有波纹扰动；水面以上的东西不能“倒”到岸上。
- **天气与季节**：
  - 雨天地面湿、有雨圈、没有硬影子；雪天屋顶、枝头、栏杆有积雪；
  - 风向在头发、衣袂、烟、草、花瓣、旗上一致；
  - 季节植物对应：春桃、夏荷、秋枫、冬梅。梅花开在雪里是对的；桃花配大雪是错的。
- **时间**：星星、萤火、河灯只在夜里；白天没有星星；月亮的亮面朝向太阳一侧。
- **重力**：没有支撑的东西会落下；灯笼、风铃、葫芦、剑穗自然下垂，随风摆的幅度合理。
- **物体完整**：前景物体被画框裁切可以，但不能凭空截断、穿插或互相穿透。

## 5. 美感

- 中国水墨加古风插画：至少 4 个景深层，有留白和雾气分层；远景淡、偏蓝，近景深、实。
- 每个镜头选一处“唯美”元素做足，比如丁达尔光、光斑、花瓣、雪、萤火、倒影、薄雾。不要什么都堆。
- 一个镜头只讲一件事：一个主体、一个动作、一个情绪。
- 色彩按分镜里给的色板。暗场里也要有一处暖色或冷色的亮点。
- 画面上的书法、字迹一律是抽象笔触，不能写出歌词。

## 6. 歌词区

- 歌词区（top / bottom / left / right）里不能有主体、高对比细节或人物。
- 歌词区背景的明暗要稳定，保证字能看清。

## 7. 技术

- 无状态：画面只由时间决定，不用 `Math.random`，帧与帧之间不保存状态。
- 静态层用 `XYT.kit.cache` 缓存，每帧绘制不超过约 15 毫秒；`ctx.filter` 只在建缓存时使用。
- 一镜跨两句时：用 `c.charT(k, 1)` 取第二句第 k 个字的时间，用 `c.lineAt(1)` 取第二句。
- 交付前必须跑：
  - `node --check`；
  - 页面启动检查；
  - `tools/motion-check.cjs` 逐帧突跳检测：镜头内相邻帧差异不能有孤立的尖峰；
  - 连续帧胶片条检查，确认人物和物体的运动连续。
